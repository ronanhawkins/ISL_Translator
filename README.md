# ISL Translator
An Irish Sign Language (ISL) recognition tool built with computer vision and machine learning.
This project was created for the **BT Young Scientist & Technology Exhibition (BTYSE) 2023**, where it received a **Highly Commended** award.
## How It Works
| File | Purpose |
|------|---------|
| `isl_dataset/` | Dataset directory — contains subfolders named after each sign (`A`, `B`, `C`, etc.), each holding training images |
| `datamaker.py` | Scans `isl_dataset/` and extracts hand landmark data from each image, storing the results in `ISL_dataset.csv` |
| `sense.py` | Trains a machine learning model using the landmark data, evaluates accuracy, and generates a confusion matrix heatmap (`heatmap.png`) |
| `ISL_dataset.csv` | Generated by `datamaker.py` — the extracted hand landmark dataset |
| `isl_model.pkl` | Trained model saved by `sense.py` |
| `transl.py` | Live prediction app — captures webcam video, overlays hand landmarks, and displays real-time ISL predictions using the trained model |
## Pipeline
1. **`datamaker.py`** → reads images from `isl_dataset/`, extracts hand landmarks via MediaPipe, and writes them to `ISL_dataset.csv`.
2. **`sense.py`** → loads `ISL_dataset.csv`, trains a classifier, saves the model as `isl_model.pkl`, and produces an accuracy heatmap (`heatmap.png`).
3. **`transl.py`** → runs a live camera feed with landmark overlays and on-screen predictions using the saved model.
